# Luxury Cosmetics Fraud Analysis 2025

A Python data analytics project exploring luxury cosmetics transaction data to identify potential fraud patterns and uncover meaningful insights.

## Project Overview
This project uses Exploratory Data Analysis (EDA) to examine transaction records, purchase amounts, payment methods, device types, and fraud indicators.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Features
- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Statistical analysis
- Fraud flag distribution analysis
- Payment method and device type comparisons
- Purchase amount analysis
- Monthly fraud trend analysis
- Correlation heatmap
- Advanced payment method vs. device type risk matrix
- Business insights and conclusions

## Dataset
File: `luxury_cosmetics_fraud_analysis_2025.csv`

The dataset contains luxury cosmetics transaction records used to explore transaction patterns and potential fraud indicators.

## Project Objectives
- Understand transaction patterns and distributions.
- Identify factors associated with flagged transactions.
- Compare transaction characteristics across categories.
- Visualize relationships and trends using professional graphs.
- Communicate data-driven findings clearly.

## Project Workflow
1. Data Loading
2. Data Understanding
3. Data Cleaning
4. Exploratory Data Analysis
5. Statistical Analysis
6. GroupBy and Pivot Table Analysis
7. Data Visualization
8. Correlation Analysis
9. Key Findings and Conclusion

## Skills Demonstrated
Python, Pandas, NumPy, Data Cleaning, EDA, Statistical Analysis, Data Visualization, and Business Insights.

## Important Note
Flagged transactions indicate potential risk and do not independently confirm fraudulent activity.
